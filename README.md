# Whaticket - Sistema de Multiatendimento

Este é o repositório público com o código compilado e otimizado do sistema Whaticket.

## 📦 Instalação

### Pré-requisitos
- Node.js (>= 16.0.0)
- PostgreSQL ou MySQL
- Redis

### Backend

```bash
cd backend
npm install
cp .env.example .env
# Configure o arquivo .env com suas credenciais
npm start
```

### Frontend

```bash
cd frontend
npm install
cp .env.example .env
# Configure o arquivo .env
npm start
```

## 📝 Notas

- Este repositório contém apenas o código compilado e otimizado
- O código fonte está disponível no repositório privado
